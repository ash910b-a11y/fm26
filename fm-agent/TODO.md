# 미완성 작업 목록

새 기능을 논의하기 전에 여기부터 본다. 이미 논의가 끝났고 만들지만 않은 것들이다.
작업을 마치면 그 항목을 지운다.

---

## 대시보드 — 만들기로 했으나 미구현

- **시즌 승률 타일** — 지금은 승·무·패와 승점만 있다
- **연승/연패 표시**
- **최근 10경기 추세 그래프** (승률·득실·점유율) — 감독이 "나중에"로 미뤄둔 항목
- **조합 승률** (예: 와튼+부아디 11전 7승) · **선수별 출전 승률**
  - `players` 에 선발 11명 **이름만** 들어 있으면 계산 가능하다 (평점 없어도 됨)
  - screenshot-prompt.md 안내 문구는 이미 반영돼 있다
  - 주의: 11명이면 짝이 55개라 표본이 적으면 우연히 높은 조합이 반드시 나온다.
    **최소 출전 수 기준**을 걸고, 절대 승률이 아니라 **팀 전체 승률 대비 차이**로 표시할 것.
    층위는 Inference, 표본 수를 항상 같이 적을 것

## 전술

- **`tactic-sets/`** — 포메이션 + 팀 지침 + 슬롯별 롤·개인 지침을 한 벌로 저장
  - 기존 `tactics/`(변경 기록)와 연결하면 "A안 → B안 이후 N경기" 비교가 자동으로 된다
  - 전술 보드의 "전술 다운로드 (.json)" 결과물이 여기로 들어가면 된다

## 정리 필요 — 동작에는 지장 없음

- **대시보드 `renderOpponents()` 가 팀명 별칭을 정규화하지 않는다.**
  `m.opponent` 문자열 그대로 묶으므로 `노팅엄` 과 `노팅엄 포레스트` 가 두 줄로 갈라진다.
  지금은 build.ps1 의 `[표기 통일]` 경고로 막고 있으나, 렌더 시 `teams.json` 별칭으로
  묶는 편이 더 튼튼하다

## 작업할 때

- **HTML·스크립트 수정은 모아서 한 번에.** (CLAUDE.md 작업 방식 8번)
- `.ps1` 은 고친 뒤 반드시 **UTF-8 BOM** 으로 재저장한다. 안 그러면 한글이 깨진다.
- 대시보드를 고친 뒤에는 브라우저로 열어 **콘솔 에러 0** 을 확인한다.
