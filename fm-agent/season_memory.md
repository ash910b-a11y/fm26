# 시즌 메모리

세션이 바뀌어도 이어져야 하는 **"지금 상태"** 한 장 요약이다. `hypotheses/`(반증 가능한 엄밀한
주장)와 다르다 — 여기는 검증 대상이 아니라 다음 세션이 바로 맥락을 잡기 위한 느슨한 메모다.

## 언제 읽는가

세션 시작 시 `coach.md` 바로 다음에 읽는다. 파일이 짧으므로 매 세션 읽어도 비용이 작다.

## 언제 갱신하는가

**감독이 명시적으로 요청할 때만** 고쳐 쓴다 (예: "메모리 갱신해", "이거 시즌 메모리에 남겨줘").
자동으로 조용히 덮어쓰지 않는다 — 그러면 감독이 모르는 사이 상태가 틀어질 수 있다.

다만 다음 상황에서는 **먼저 반영해도 되는지 묻는다** (알아서 고치지 않는다):
- 전술 변경(`tactics/*.json`)이 새로 등록됐을 때
- 가설(`hypotheses/`)이 `supported`/`rejected` 로 결론 났을 때
- 감독이 세션 중 목표나 방향을 새로 밝혔을 때

## 오래됐다 싶으면

`digest.md`를 보다가 "마지막 갱신" 시점 이후로 경기가 꽤 지났다는 게 눈에 띄면, 별도로
세지 말고 그냥 한 번 자연스럽게 짚는다 ("이 메모리 좀 됐는데 갱신할까요?" 정도). 매번
확인하거나 스스로 카운트하지 않는다 — 눈에 띌 때만.
