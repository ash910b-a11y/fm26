# 나만의 FM 에이전트 — 시작 세트

```
fm-agent/
├─ README.md        이 파일
├─ coach.md         AI 코치 프롬프트  ← [ ] 부분을 직접 채우세요
├─ schema.md        스크린샷 → JSON 규칙 (에이전트가 읽는 지시서)
├─ teams.json       표준 팀명 목록 (오기 방지용)
├─ competitions.json 표준 대회명 목록 (+ 시즌 형식)
├─ reference-shape.json  기준 형태 — 데이터가 아니라 **당신의 전술 의도**. 직접 고치는 파일
├─ matches/         경기 JSON 저장소
├─ screenshots/     원본 스크린샷 (절대 지우지 않기)
├─ squad/선수_능력치_기록표.csv  **선수명·포지션·발·특성·능력치의 유일한 기준.** 직접 고칩니다
├─ data/            역할·팀지침·개인지침·특성(PPM) 정의 — FM26 자료
├─ hypotheses/      가설 — 반증 조건이 있는 해석만
├─ tactics/         전술 변경 기록
├─ digest.md        시즌 요약본 (자동 생성) — AI 분석은 이것만 읽습니다
├─ season_memory.md 지금 상태 한 장 요약 — 세션 시작 시 읽습니다
├─ build.ps1        검증 + 대시보드·전술보드 갱신 + screenshot-prompt·digest 생성
├─ screenshot-prompt.md  스크린샷을 경기 JSON으로 바꾸는 지시서
├─ tactics-board.html 전술 보드 (수석코치 조언 프롬프트 복사)
└─ dashboard.html   더블클릭하면 열리는 시즌 대시보드
```

## 쓰는 순서

**1-A. 경기 기록하기 · 스크린샷 → JSON**

`screenshot-prompt.md`를 다른 AI에 스크린샷과 함께 보내 JSON을 받으세요.
파일명(`2025-10-25-vs-에버턴.json`)에 맞춰 `matches/`에 저장하고 build.ps1을 실행하면 됩니다.
확실하지 않은 값은 AI가 `uncertain`에 남기므로, 저장 전 JSON을 한 번 확인하세요.

> 스크린샷은 여전히 찍어서 `screenshots/`에 넣으세요. AI에게 보내지만 않는 겁니다 —
> 숫자가 이상할 때 돌아갈 원본이 있어야 합니다.

**1-B. 경기 기록하기 · 스크린샷** — FM에서 경기 결과·통계·**포메이션** 화면을 캡처(Win+Shift+S)해
`screenshots/`에 넣고, AI에게 이렇게 말합니다:

> `schema.md` 규칙대로 이 스크린샷을 `matches/`에 JSON으로 저장해줘.

**2. 대시보드 갱신** — 저장 후:

```bash
powershell -ExecutionPolicy Bypass -File "C:\Users\LSH\Desktop\CLAUDE\fm-agent\build.ps1"
```

경기 수와 함께 아래 항목이 경고로 출력됩니다:
팀명·대회명 오기, `season` 누락/형식 오류(`YYYY/YY`), 불확실한 값,
중복 경기, 수치 논리 오류(유효슈팅>슈팅 등), 득점자 수 불일치.
그다음 `dashboard.html`을 더블클릭(또는 새로고침).

> **선수 평점 섹션**은 JSON에 `players` 배열이 있을 때만 나옵니다. 포메이션 화면
> (평점이 붙은 라인업)을 같이 캡처해서 주면 자동으로 채워집니다.
>
> **패스맵의 "기준"** 드롭다운은 세 종류를 고를 수 있습니다.
> ① `reference-shape.json`의 역할 기준 형태 — **모델(의도)이지 측정값이 아닙니다.**
> ② 시즌 평균, ③ 다른 경기 — 이 둘은 실제 데이터이며 **경기 2개부터** 선택지에 나타납니다.
> 점선 원이 기준, 실선 원이 실제입니다. ①이 마음에 안 들면 그 파일을 고치세요 — 그러라고 만든 파일입니다.

> **패스맵 섹션**은 `passmap`이 있을 때만 나옵니다. 좌표와 연결 강도는 화면의 숫자가 아니라
> **스크린샷을 눈으로 읽은 추정치**라 `approx: true`로 표시됩니다. 패스 개수·성공률은
> FM 화면에 없으므로 기록하지 않습니다 — 그 숫자가 어딘가에 보인다면 잘못된 겁니다.

> build.ps1을 돌리지 않고 보고 싶으면, 대시보드 우측 상단 **"matches 폴더 다시 읽기"**로
> 폴더를 골라도 즉시 반영됩니다. (검증은 안 돌아갑니다)

**2-1. 스쿼드 갱신** — `squad/선수_능력치_기록표.csv`를 직접 고치고 build.ps1만 돌리면 됩니다.
변환 단계는 없습니다. 엑셀에서 저장한 CP949든 UTF-8이든 알아서 읽습니다.

이 CSV가 **선수명의 유일한 기준**입니다. 경기 기록에 여기 없는 이름이 들어가면 `[선수 확인]`
경고가 뜹니다 — 잘린 이름이나 오타를 잡아주는 장치입니다.

**3. 코치와 대화** — 새 세션을 시작할 때:

> `coach.md`를 읽고 그 역할로 이번 시즌을 함께 봐줘.

## PowerShell 파일 인코딩 메모

`.ps1`을 새로 만들거나 고칠 때는 **UTF-8 BOM**으로 저장해야 합니다.
BOM이 없으면 Windows PowerShell 5.1이 한글을 깨뜨려 파싱 오류가 납니다.
