# 삼국지14 PK 참모 에이전트

이 폴더는 `fm-agent/` 와 **별개 프로젝트**다. 삼국지14 PK 관련 질문을 받았을 때만 읽는다.
FM 세션에서는 이 폴더를 읽지 않는다.

## 이 도구가 답하는 질문

- 관문·거점에 누구를 수비로 배치할까
- 출진할 때 누구와 누구를 같이 보내면 개성이 맞물리나
- 이 부대에 어떤 진형·전법이 맞나

## 세션 시작 시

1. 이 문서를 읽는다.
2. `rules/판단기준.md` 를 읽는다 — 배치·조합을 어떤 기준으로 고르는지가 거기 있다.
3. `generals.csv` 를 읽는다 — 감독이 보유한 장수의 유일한 기준.

`data/` 는 질문에 걸리는 항목만 찾아 읽는다. 전체를 통째로 읽지 않는다.

## 파일 지도

| 경로 | 용도 |
|---|---|
| `generals.csv` | **보유 장수의 유일한 기준.** 감독이 직접 관리 |
| `data/개성.csv` | 개성 이름·효과·범위·수치 |
| `data/진형.csv` | 진형별 능력 보정과 용도 |
| `data/전법.csv` | 전법 효과·소모·사거리 |
| `rules/판단기준.md` | 배치·조합 판단 규칙 |
| `research/` | 웹에서 모은 원자료. **확정 데이터가 아니다** |
| `screenshots/` | 게임 화면 원본. 절대 삭제 금지 |

## 신뢰도 3층 — 반드시 구분해서 말한다

`data/*.csv` 의 `출처` 칸이 층을 결정한다.

| 출처 표기 | 층 | 말하는 방식 |
|---|---|---|
| `게임내` | **확정** | 그냥 단정한다. 감독이 게임 화면에서 직접 확인한 값 |
| `공식매뉴얼` | **확정** | 단정한다 |
| `커뮤니티` | **참고** | "커뮤니티 기준으로는" 을 반드시 붙인다 |
| `추정` | **가설** | "확인 안 된 값입니다만" 을 먼저 붙인다. 수치를 근거로 쓰지 않는다 |
| 빈칸 | **없음** | 모른다고 말한다. **채워 넣지 않는다** |

**개성 효과를 기억으로 채우지 않는다.** 이게 이 프로젝트의 유일한 절대 규칙이다.
`data/개성.csv` 에 없는 개성을 물어보면 "그 개성은 아직 안 넣으셨어요" 라고 말하고,
게임 내 개성 설명 화면을 요청한다. 그럴듯하게 지어내면 판이 틀어진다.

## 데이터 채우는 법

**가장 정확한 경로는 게임 안이다.** 삼국지14는 개성·전법·진형 설명을 게임 내에서 다 보여준다.
감독이 그 화면을 스크린샷으로 주면 `출처=게임내` 로 넣는다. 이게 1순위다.

웹 검색은 보조다. 이 세션 기준으로 나무위키·루리웹·디시·공식매뉴얼 도메인은
네트워크 프록시에서 전부 차단되어 있어 **검색 요약본만** 받을 수 있고,
그 요약본은 서로 어긋나는 경우가 있었다. 그래서 웹에서 온 값은 `출처=커뮤니티` 로만 넣는다.

## 인코딩

CSV 는 **UTF-8 BOM** 으로 저장한다. Windows 엑셀에서 한글이 안 깨진다.
(`fm-agent/squad/` 의 CSV 는 CP949 라 규칙이 다르다. 섞지 않는다.)
