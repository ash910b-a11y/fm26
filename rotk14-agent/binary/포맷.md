# s14ko 신무장 파일 포맷 — 해석 결과

삼국지14 PK 의 신무장 내보내기 파일(`*.s14ko`). **감독이 만든 샘플 4개로 역분석했다.**

| 샘플 | 내용 |
|---|---|
| `samples/A.s14ko` | 테/스트/무장, 여성, 통솔100·무력1·지력2·정치3·매력4, 개성 응원·견수·낭비·산전·신장, 진형 방원, 전법 철벽 |
| `samples/B.s14ko` | A 에서 **통솔만 99** |
| `samples/D.s14ko` | A 에서 **개성 5번째만** 신장 → 다른 금색 |
| `samples/M.s14ko` | 매란 (대조군) |

## 가장 중요한 사실 — 체크섬이 없다

**A 와 B 는 딱 1바이트만 다르다.** 통솔을 100 → 99 로 바꿨더니 `0x5E` 한 자리만
바뀌었고 그 외에는 완전히 동일했다. **파일을 직접 만들어도 게임이 받아들인다는 뜻이다.**

D 도 마찬가지로 개성 한 칸을 바꿨더니 `0x6B` 한 자리만 달라졌다.

## 파일 구조

전체 **1137바이트 고정**. 실제 데이터는 `0x00~0x89` 뿐이고 **뒤쪽은 전부 0 패딩**이다.

| 오프셋 | 크기 | 필드 | 근거 |
|---|---|---|---|
| `0x00` | 16 | `"SAN14EDITPERSON\0"` | 네 파일 모두 동일 |
| `0x10` | 8 | `01 00 00 00 00 00 04 00` | 네 파일 모두 동일. 버전 또는 플래그 |
| `0x18` | 6 | **성** (UTF-16LE, 최대 3자) | 테 / 매 |
| `0x1E` | 6 | **명** (UTF-16LE, 최대 3자) | 스트 / 란 |
| `0x24` | 6 | **자(字)** (UTF-16LE, 최대 3자) | 무장 / 없음 |
| `0x2A` | 2 | `58 1B` 고정 | 양쪽 동일 |
| `0x2C` | 1 | `01` 고정 | |
| `0x2D` | 2 | uint16 — A=170, M=188 | 미상 (생년? 초상?) |
| `0x2F` | 2 | uint16 — A=239, M=286 | 미상 |
| `0x5E` | 1 | **통솔** | A=100 → B=99 로 확정 |
| `0x5F` | 1 | **무력** | A=1 |
| `0x60` | 1 | **지력** | A=2 |
| `0x61` | 1 | **정치** | A=3 |
| `0x62` | 1 | **매력** | A=4 |
| `0x63` | 2 | **개성 1** (uint16 LE) | |
| `0x65` | 2 | **개성 2** | |
| `0x67` | 2 | **개성 3** | |
| `0x69` | 2 | **개성 4** | |
| `0x6B` | 2 | **개성 5** | D 에서 이 자리만 바뀜 |
| `0x75` | 2 | uint16 — A=16, M=1736 | **전법으로 추정** |
| `0x79` | 4 | **진형 4칸** (uint8 × 4) | A=[8,0,0,0] 방원 하나만 넣었다 |
| `0x84` | 2 | A=[1,1] M=[47,5] | 미상 |
| `0x86` | 1 | `0D` 고정 | |
| `0x87` | 3 | A=[0,0,0] M=[248,173,32] | 미상 |

**능력치는 순서까지 입력값과 정확히 일치한다** — `0x5E` 부터 `64 01 02 03 04`.

## 알아낸 ID

입력 순서가 파일에 그대로 보존된다(정렬되지 않는다).

| 종류 | 이름 | ID |
|---|---|---|
| 개성 | 응원 | 96 |
| 개성 | 견수 | 7 |
| 개성 | 낭비 | 31 |
| 개성 | 산전 | 69 |
| 개성 | 신장 | 150 |
| 개성 | (D 에서 넣은 금색) | 48 |
| 진형 | 방원 | 8 |
| 전법 | 철벽 | 16 (추정) |

**매란의 값** — 능력치 95/73/88/87/100, 개성 [109, 88, 182, 129, 58],
진형 [22, 23, 17, 15], 전법 1736(?)

## 다음에 필요한 것 — ID 표

구조는 뚫렸지만 **개성·진형·전법의 ID 전체 표가 없다.** 지금 아는 건 여섯 개뿐이다.

신장이 150 이고 낭비가 31 인 걸 보면 **게임 안 목록 순서가 곧 ID** 일 가능성이 높다.
그렇다면 감독이 게임의 개성 선택 목록을 **표시 순서 그대로** 알려주면
번호를 매기는 것만으로 전체 표가 만들어진다. 우리가 아는 여섯 개로 검증도 된다.

진형과 전법도 같은 방식이다.
