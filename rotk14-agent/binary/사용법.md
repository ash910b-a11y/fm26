# 개성 ID 찾기 — 사용법

파워셸을 몰라도 된다. **더블클릭이나 드래그 한 번이면 끝난다.**

## 1. 파일 두 개를 같은 폴더에 둔다

- `찾기_더블클릭.bat`
- `GaeseongID.ps1`

둘이 같은 폴더에 있어야 한다. 바탕화면이든 어디든 상관없다.

## 2. 게임 데이터 파일을 찾는다

삼국지14 설치 폴더 안에 있다. 보통 이런 곳이다.

```
C:\Program Files (x86)\Steam\steamapps\common\Romance of the Three Kingdoms XIV
```

스팀이면 **라이브러리에서 게임 우클릭 → 관리 → 로컬 파일 보기** 가 제일 빠르다.

그 안에서 **크기가 100MB 넘는 파일**을 찾는다. 폴더 안에서 보기를 "자세히" 로 바꾸고
크기 순으로 정렬하면 바로 보인다.

## 3. 드래그한다

찾은 파일을 **`찾기_더블클릭.bat` 아이콘 위로 끌어다 놓는다.**

검은 창이 잠깐 뜨고, 1분쯤 뒤에 **메모장이 열리면서 결과가 나온다.**

드래그가 안 되면 `찾기_더블클릭.bat` 을 그냥 더블클릭한다.
경로를 물어보면 파일을 창 안으로 끌어다 놓고 엔터를 친다.

## 4. 결과를 붙여넣는다

메모장에 나온 내용을 **전부 복사해서** 대화창에 붙여넣으면 된다.
길어야 스무 줄이다.

## 나오는 결과 읽는 법

이런 식으로 나온다.

```
견수   ID=7    -> 0x1A2B3C, 0x1A2C40
낭비   ID=31   -> 0x1A3D80
```

`못 찾음` 만 잔뜩 나오면 그 파일에는 개성 이름이 없거나 압축되어 있다는 뜻이다.
**그 경우엔 포기하고 게임에서 직접 만드는 게 맞다.** 다른 파일을 더 찾아볼 필요는 없다.

위치가 나오고 **간격이 일정하면 성공이다.** 그 간격이 레코드 크기이고,
거기서 전체 개성 ID 표를 역산할 수 있다.

## 안 될 때

- **"이 앱이 PC를 보호했습니다"** 가 뜨면 → `추가 정보` → `실행`
- 검은 창이 순식간에 사라지면 → `.bat` 을 우클릭 → `편집` 으로 열어서 내용이 있는지 확인
- 그래도 안 되면 그냥 알려달라. 다른 방법을 찾는다.
