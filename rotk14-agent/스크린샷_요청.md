# 감독님이 찍어주셔야 할 화면

웹으로는 안 채워졌다. 게임 안이 제일 정확하고 빠르다.
아래 순서대로 하나씩 주시면 된다. **한 번에 다 안 주셔도 된다.**

## 1순위 — 지금 당장 쓸 것

**보유 장수 목록.** 무장 일람에서 통솔·무력·지력·정치·매력이 같이 보이는 화면.
세력이 크면 여러 장 나뉘어도 괜찮다. → `generals.csv` 를 채운다.

**궁금한 장수의 상세 화면.** 개성 5칸과 전법·진형이 보이는 화면.
관문에 세울 후보, 출진에 넣을 후보부터 주시면 된다.

## 2순위 — 판단의 근거가 되는 것

**개성 설명 화면.** 개성 위에 커서를 올렸을 때 뜨는 효과 설명.
`data/개성.csv` 에서 **효과 칸이 비어 있는 개성부터** 채운다. 지금 비어 있는 건 이렇다.

- 신기, 복룡, 비장, 확삭, 임재, 봉추 — 이름만 알고 효과를 모른다
- 견수, 신장 — 효과는 아는데 수치를 모른다
- 소탕 — 어떤 능력치가 오르는지 모른다
- 간웅 — 자기 부대에도 걸리는지 아닌지가 갈린다

**진형 설명 화면.** 진형별 공군·방어·공성·파성 수치.
`data/진형.csv` 가 지금 서술만 있고 숫자가 통째로 비어 있다.

**전법 설명 화면.** `data/전법.csv` 는 아예 비어 있다. 헤더만 있는 상태다.

## 3순위 — 있으면 좋은 것

**관문·거점 목록.** 어느 관문이 어느 세력과 붙어 있는지.
후방 관문에 좋은 장수를 낭비하지 않으려면 이게 필요하다.

**친애·혈연 관계.** 부대당 10% 버프가 걸리는 관계라 조합에서 꽤 크다.

---

## 규칙

받은 화면의 값은 `출처=게임내` 로 넣는다. **이게 유일한 확정 데이터다.**
화면에 안 보이는 값은 빈칸으로 둔다. 추측해서 채우지 않는다.
