# 웹 AI 에게 던질 수집 프롬프트

웹 접근이 되는 AI(브라우징 켠 ChatGPT·Gemini·Perplexity 등)에 붙여넣고,
받은 CSV 를 `data/` 의 해당 파일에 이어 붙인다.

## 쓰는 법

- **세 개를 한 번에 시키지 않는다.** 개성 → 진형 → 전법 순서로 하나씩 시킨다.
  한 번에 시키면 중간에 잘리고, 잘린 걸 눈치 못 채면 데이터가 조용히 비어버린다.
- 개성은 수백 개라 한 번에 안 나온다. **50개씩 끊어서** 받는다. 프롬프트 안에 그렇게 적혀 있다.
- 받은 결과를 `data/개성.csv` 맨 아래에 붙이면 된다. 헤더 줄은 빼고 붙인다.
- 붙인 뒤 감독이 "웹AI 자료 넣었어" 라고만 하면 중복·충돌을 정리한다.

## 받은 자료의 신뢰도

`출처` 칸에 URL 이 적힌 행은 전부 **커뮤니티 층**이다. 확정이 아니다.
게임 화면에서 확인되면 그때 `게임내` 로 승격한다. `GUIDE.md` 의 3층 규칙을 따른다.

## 프롬프트 1 — 개성

```
너는 삼국지14 with 파워업키트(PK)의 데이터를 수집하는 조사원이다.
결과를 사람이 읽을 글이 아니라 다른 프로그램이 먹을 CSV 로 낸다.

[해야 할 일]
삼국지14 PK 의 "개성" 목록과 각 개성의 효과를 웹에서 찾아 CSV 로 정리해라.

[반드시 지킬 규칙 — 이게 제일 중요하다]
1. 모르는 값은 반드시 빈칸으로 둬라. 추측해서 채우지 마라.
   그럴듯한 추측이 빈칸보다 훨씬 나쁘다. 이 데이터로 실제 판단을 할 거라
   틀린 값 하나가 판을 통째로 어긋나게 한다.
2. 실제로 웹에서 확인한 내용만 적어라. 네 기억으로 채우지 마라.
   삼국지 시리즈는 넘버링마다 시스템이 달라서 다른 편 지식을 섞으면 전부 틀린다.
3. 자료마다 내용이 다르면 그 개성의 비고 칸에 "출처마다 다름: A 는 X, B 는 Y" 로
   양쪽을 다 적어라. 네가 임의로 하나를 고르지 마라.
4. 출처는 반드시 실제 URL 을 적어라. "나무위키" 같은 사이트 이름만 적지 마라.
5. 삼국지14 무인편(무印) 이 아니라 14 PK 기준으로 찾아라.
   구분이 안 되면 비고에 "PK 여부 미확인" 이라고 적어라.

[출력 형식]
아래 헤더의 CSV 만 출력한다. 설명·인사·마크다운 코드펜스 없이 CSV 만 낸다.

개성명,색,분류,효과,대상,범위,수치,중첩,출처,비고

각 칸의 의미:
- 개성명: 한글 이름
- 색: 금 / 청 / 적 중 하나. 모르면 빈칸
- 분류: 자기강화 / 범위버프 / 범위디버프 / 수성 / 사기 / 상태이상 / 내정 / 계략 /
        일기토 / 이동 / 단점 중에서 고른다. 안 맞으면 짧게 새로 지어도 된다
- 효과: 게임 내 설명문에 가깝게. 한 문장
- 대상: 자신 / 아군부대 / 적부대 / 거점 / 세력 중 하나
- 범위: 숫자 칸 수. 범위 개념이 없으면 빈칸
- 수치: +10% 같은 형태. 여러 개면 세미콜론으로 구분
- 중첩: 같은 개성 2명 이상이 겹칠 때 효과가 누적되는지. 확인된 것만 적는다
- 출처: 실제 URL
- 비고: 불확실한 점, 출처 간 충돌, 조건부 발동 등

[CSV 주의]
- 칸 안에 쉼표가 들어가면 그 칸 전체를 큰따옴표로 감싼다
- 줄바꿈을 칸 안에 넣지 마라
- 헤더는 첫 블록에만 한 번 넣는다
- **모든 행은 정확히 헤더와 같은 개수의 칸을 가져야 한다.**
  값이 없어도 쉼표는 그대로 찍어서 자리를 지켜라. 칸이 밀리면 데이터가 통째로 망가진다.
- **URL 뒤에 각주 마커나 인용 기호를 붙이지 마라.** 출처 칸에는 순수한 URL 문자열만 넣는다.
- **출처를 마크다운 링크로 만들지 마라.** `[텍스트](주소)` 형태로 쓰면 비고가 주소 안으로
  빨려 들어가 데이터가 망가진다. 벌거벗은 URL 만 쓴다.

[분량]
한 번에 50행까지만 내라. 다 내고 나서 마지막 줄에
`### 여기까지 N개, 다음 있음` 또는 `### 여기까지 N개, 끝` 이라고 적어라.
내가 "계속" 이라고 하면 헤더 없이 다음 50행을 이어서 낸다.

[우선순위]
자료가 많은 것부터 말고, 아래 개성부터 먼저 찾아라. 이것들이 지금 제일 급하다.
신기, 복룡, 비장, 확삭, 임재, 봉추, 견수, 신장, 소탕, 간웅, 견뢰, 통찰, 악주, 효웅, 감수
특히 "간웅이 자기 자신 부대에도 적용되는지" 는 자료가 엇갈리니 꼭 확인해라.
그다음부터는 관문·성 수비에 영향을 주는 개성과 부대 전투용 개성을 우선한다.
```

## 프롬프트 2 — 진형

```
너는 삼국지14 with 파워업키트(PK)의 데이터를 수집하는 조사원이다.

[해야 할 일]
삼국지14 PK 의 "진형" 전체 목록과 각 진형의 능력 보정 수치를 웹에서 찾아 CSV 로 정리해라.

[반드시 지킬 규칙]
1. 모르는 값은 빈칸으로 둬라. 추측 금지. 특히 수치를 지어내지 마라.
2. 웹에서 확인한 것만 적어라. 기억으로 채우지 마라.
3. 자료가 엇갈리면 비고에 양쪽을 다 적어라.
4. 출처는 실제 URL.
5. PK 기준. 오리지널과 PK 가 다르면 비고에 적어라.

[출력 형식]
아래 헤더의 CSV 만 출력한다. 설명 없이 CSV 만.

진형명,분류,공군,방어,공성,파성,이동,용도,출처,비고

각 칸의 의미:
- 진형명: 한글 이름 (어린, 봉시, 방원, 안행, 학익, 추행, 장사, 사이 등 전부)
- 분류: 야전 / 공성병기 / 수군 / 이민족전용 중 하나
- 공군 / 방어 / 공성 / 파성 / 이동: 게임에 표시되는 보정값 그대로.
  등급(A~E)으로 나오면 등급을, 배율이면 배율을 적고 어느 쪽인지 비고에 밝혀라
  **숫자 칸에는 숫자만 넣어라.** "20(기본), 시정10 시 25" 처럼 쓰지 말고
  칸에는 기본값 20 만 넣고 조건부 상승은 비고로 빼라
- 용도: 실전에서 뭐에 쓰는 진형인지 한 문장
- 출처: URL
- 비고: 특수 효과. 예를 들어 방원이 일기토를 회피한다는 것 같은 것

[CSV 주의]
- 칸 안에 쉼표가 들어가면 그 칸 전체를 큰따옴표로 감싼다
- 줄바꿈을 칸 안에 넣지 마라
- **모든 행은 정확히 헤더와 같은 개수의 칸을 가져야 한다.**
  값이 없어도 쉼표는 그대로 찍어서 자리를 지켜라. 칸이 밀리면 데이터가 통째로 망가진다.
- **URL 뒤에 각주 마커나 인용 기호를 붙이지 마라.** 출처 칸에는 순수한 URL 문자열만 넣는다.
- **출처를 마크다운 링크로 만들지 마라.** `[텍스트](주소)` 형태로 쓰면 비고가 주소 안으로
  빨려 들어가 데이터가 망가진다. 벌거벗은 URL 만 쓴다.

[꼭 확인할 것]
- 각 진형을 쓰려면 필요한 조건(무장별 습득 여부)이 있는지
- 진형마다 최대 부대 수나 병력 제한이 있는지
- 방원 외에 일기토 회피가 되는 진형이 또 있는지
- 진형별로 유리한 지형이 정해져 있는지 (산악·삼림·수상 등). 있으면 비고에 적어라
- 특정 진형과 방향이 맞는 개성이 있는지 (예: 장사 진형과 산전 개성).
  이건 조합을 짤 때 쓸 거라 확인되는 대로 비고에 남겨라
```

## 프롬프트 3 — 전법

```
너는 삼국지14 with 파워업키트(PK)의 데이터를 수집하는 조사원이다.

[해야 할 일]
삼국지14 PK 의 "전법" 목록과 각 전법의 효과·수치를 웹에서 찾아 CSV 로 정리해라.

[반드시 지킬 규칙]
1. 모르는 값은 빈칸. 추측 금지.
2. 웹에서 확인한 것만. 기억으로 채우지 마라.
3. 자료가 엇갈리면 비고에 양쪽 다.
4. 출처는 실제 URL.
5. PK 기준.

[출력 형식]
아래 헤더의 CSV 만 출력한다. 설명 없이 CSV 만.

전법명,분류,효과,수치,대상,사거리,소모,출처,비고

각 칸의 의미:
- 전법명: 한글 이름
- 분류: 공격 / 방어 / 지원 / 방해 / 회복 / 계략 중 하나
- 효과: 한 문장
- 수치: 데미지 배율, 상태이상 확률, 지속 턴 등
- 대상: 단일 / 광역 / 자신 / 아군 중 하나. 광역이면 몇 칸인지도
- 사거리: 칸 수
- 소모: 사용에 드는 것 (기력·사기 등). 무엇을 소모하는지 이름까지 적어라
- 출처: URL
- 비고: 발동 조건, 지력·무력 의존 여부

[CSV 주의]
- 칸 안에 쉼표가 들어가면 그 칸 전체를 큰따옴표로 감싼다
- 줄바꿈을 칸 안에 넣지 마라
- **모든 행은 정확히 헤더와 같은 개수의 칸을 가져야 한다.**
  값이 없어도 쉼표는 그대로 찍어서 자리를 지켜라. 칸이 밀리면 데이터가 통째로 망가진다.
- **URL 뒤에 각주 마커나 인용 기호를 붙이지 마라.** 출처 칸에는 순수한 URL 문자열만 넣는다.
- **출처를 마크다운 링크로 만들지 마라.** `[텍스트](주소)` 형태로 쓰면 비고가 주소 안으로
  빨려 들어가 데이터가 망가진다. 벌거벗은 URL 만 쓴다.

[분량]
한 번에 50행까지. 마지막 줄에 `### 여기까지 N개, 다음 있음` 또는 `### 여기까지 N개, 끝`.
내가 "계속" 하면 헤더 없이 이어서.

[꼭 확인할 것]
- 전법마다 쓸 수 있는 진형이 정해져 있는지. 있으면 비고에 적어라
- 지속시간이 있는 전법은 며칠 유지되는지
- 같은 전법을 두 부대가 겹쳐 걸면 효과가 누적되는지, 덮어써지는지

[우선순위]
아래 전법부터 먼저 찾아라. 이미 단서가 있어서 확인만 하면 되는 것들이다.
- 철벽 (방어 +50%, 20일 유지로 알려져 있음. 정확한 수치와 조건 확인)
- 구축 (피해량 8, 단일. 수군 주가 전용)
- 강습 (피해량 10, 단일 + 혼란 부여. 수군 몽충 전용)
- 시람 (피해계수 8, 1칸 광역. 수군 누선 전용)
그다음은 사용 빈도가 높은 기본 전법과 상태이상 계열 전법을 우선한다.
```

## 프롬프트 4 — 전법 이어받기 (다른 AI 로 새로 시작할 때)

앞의 AI 가 50개를 주고 끊겼다. 새 세션에서 이걸 쓰면 중복 없이 나머지만 받는다.

```
너는 삼국지14 with 파워업키트(PK)의 데이터를 수집하는 조사원이다.
앞선 작업에서 전법 50개를 이미 수집했다. 그 50개는 다시 내지 마라.

[이미 가진 50개 — 전부 제외한다]
분전 돌격 급습 제사 화시 연노 격려 철벽 경파 견제 대갈 교란 업화 저지 혼란 도발 매성 고무 치료 진정 정란 충차 투석 구축 강습 시람 구갑대열 안식사법 아수라진 전상돌격 위무지강 천하무쌍 군신 만인적 신산귀모 대기대덕 단기구 신기묘산 대호웅략 신화계 경국지무 팔문금쇄 함진영 태평요술 신위천관 신궁 호기충천 인왕서기 료래료래 백전연마

[해야 할 일]
위 50개를 뺀 **나머지 전법 전부**를 웹에서 찾아 CSV 로 정리해라.
고유전법(무장 1인 전용)이 많이 남아 있을 것이다. 그쪽을 먼저 훑어라.

[반드시 지킬 규칙]
1. 모르는 값은 빈칸. 추측 금지.
2. 웹에서 확인한 것만. 기억으로 채우지 마라.
3. 자료가 엇갈리면 비고에 양쪽 다.
4. 출처는 실제 URL.
5. PK 기준.

[출력 형식]
아래 헤더의 CSV 만 출력한다. 설명 없이 CSV 만.

전법명,분류,습득,효과,수치,대상,사거리,쿨타임,거점공격,의존능력,출처,비고

각 칸의 의미:
- 분류: 공격 / 공격(원거리) / 공격(제압) / 공격(병기) / 방어 / 방해(계략) / 계략 / 지원 / 회복
- 습득: 공용 / 교역 / 고유(인물명). 고유면 반드시 괄호에 무장 이름을 넣어라
- 효과: 한 문장
- 수치: "피해 위력15 / 혼란 위력8" 처럼. 지속일수가 있으면 "위력28·5일" 형태로
- 대상: 단일 / 광역(N칸) / 자신 / 아군(광역) / 아군+적
- 사거리: 칸 수
- 쿨타임: 일 단위 숫자만 (12, 18, 22 등)
- 거점공격: 거점을 상대로 발동하면 O, 안 하면 X. **모르면 빈칸으로 둬라**
```

## 받고 나서 확인할 것

붙여넣기 전에 감독이 직접 볼 것 두 가지다.

1. **빈칸이 하나도 없으면 의심한다.** 전부 채워져 있으면 웹 AI 가 지어냈을 가능성이 높다.
   진짜로 조사하면 반드시 빈칸이 남는다.
2. **출처가 URL 이 아니라 사이트 이름이면 의심한다.** "나무위키" 만 적혀 있으면
   실제로 열어본 게 아닐 수 있다.

둘 중 하나라도 걸리면 그 배치는 버리고 다시 시킨다.
